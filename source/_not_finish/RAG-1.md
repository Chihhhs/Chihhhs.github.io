## RAG 系統

RAG（Retrieval-Augmented Generation，檢索增強生成）是一種是一種結合檢索及生成的技術，目的是為了彌補 LLM 的某些限制，使生成內容更準確和實用。
以下是需要 RAG 的主要原因：

1. 解決知識更新問題
2. 提升專業領域的準確性
3. 解決「幻覺問題」（Hallucination）
4. 減少模型規模依賴

### LLM Enbedding 及向量建立

LLM（Large Language Model）具有優異的文本理解與生成能力，但要實現其與資料庫的結合，Embedding 技術不可或缺。以下是建立流程的核心步驟：

1. 資料轉換為向量
使用 LLM 將資料轉換為高維向量表示，向量可保留語意信息，成為檢索的基礎。
2. 向量資料庫技術
    + FAISS（Facebook AI Similarity Search）： 開源工具，用於高效檢索和聚類相似向量。
    + 向量資料庫中的數據可以快速支持基於上下文的檢索。
3. 應用場景
當用戶提出查詢時，系統會將其轉換為向量，並利用相似度算法檢索相關資料，再由 LLM 生成對應回答。

### 相似度搜尋

相似度搜尋是一項核心技術，用於從大型資料集中快速提取與查詢最相符的內容。以下為技術應用細節：

1. 原理
透過計算向量之間的歐幾里得距離或餘弦相似度，系統能有效判定數據的相關性。

2. 技術優勢
    + 快速：支援數百萬筆數據的即時檢索。
    + 精確：結合上下文，使返回結果更具語意相關性。
    + 可擴展：能夠應對數據量增長的需求。

3. 實際研究

研究透過 FAISS 與 RAG（Retrieval-Augmented Generation）技術，結合 LLM 實現了高度自動化的威脅情資分析。
